## 📁 Projects

### ✅ Task 1 — Term Deposit Subscription Prediction (Bank Marketing)
**Goal:** Predict if a bank customer will subscribe to a term deposit after a marketing campaign.  
**Dataset:** Bank Marketing Dataset (UCI)  
**What I did:**
- Explored and encoded all categorical features
- Trained Logistic Regression and Random Forest classifiers
- Evaluated using Confusion Matrix, F1-Score, and ROC Curve
- Used SHAP/LIME to explain model predictions

**Skills:** Classification, Feature Encoding, Explainable AI (XAI)

---

### ✅ Task 2 — Customer Segmentation Using K-Means Clustering
**Goal:** Group customers based on spending habits and suggest marketing strategies for each group.  
**Dataset:** Mall Customers Dataset  
**What I did:**
- Performed Exploratory Data Analysis (EDA)
- Applied K-Means Clustering to find customer segments
- Visualized clusters using PCA / t-SNE
- Proposed marketing strategies for each segment

**Skills:** Unsupervised Learning, K-Means, Dimensionality Reduction, Business Insights

---

### ✅ Task 3 — Household Energy Consumption Forecasting
**Goal:** Forecast short-term energy usage using historical time series data.  
**Dataset:** Household Power Consumption Dataset  
**What I did:**
- Parsed and resampled time series data
- Engineered features like hour of day and weekday/weekend
- Compared ARIMA, Prophet, and XGBoost forecasting models
- Plotted actual vs predicted energy usage

**Skills:** Time Series Forecasting, Feature Engineering, MAE/RMSE Evaluation

---

### ✅ Task 4 — Loan Default Risk & Business Cost Optimization
**Goal:** Predict the chance of a loan default and find the best decision threshold to minimize business loss.  
**Dataset:** Home Credit Default Risk Dataset  
**What I did:**
- Cleaned and preprocessed the dataset
- Trained Logistic Regression and CatBoost classifiers
- Defined cost values for false positives and false negatives
- Adjusted the model threshold to minimize total business cost

**Skills:** Binary Classification, Cost-Based Evaluation, Risk Modeling, Feature Importance
